## Организация кода

`task-service.js` - содержит только прикладную логику (9 функций для работы с задачами). Не работает с DOM и не выводит сообщения в консоль.
`task-selectors.js` - отвечает за фильтрацию данных. Функция `getVisibleTasks` вычисляет, какие задачи должны быть показаны на экране в зависимости от выбранного фильтра («Все», «В работе», «Выполненные»).
`task-view.js` - отвечает за отображение. Создает DOM-карточки задач, обновляет сводку и показывает пустые состояния. Не меняет данные и не обрабатывает клики.
`main.js` - управляет состоянием приложения (хранит полный массив `currentTasks` и `currentFilter`), обрабатывает события (клики по кнопкам и фильтрам) и вызывает функции отрисовки.

## Отладка и клавиатура

Точка останова была установлена на строке `const idStr = card.dataset.taskId;` в функции `handleTaskListClick`. В момент выполнения: `event.target` — `span.action-label`, `event.currentTarget` — `ul#task-list`, `dataset.taskId` — `"4"` (строка), числовой `id` — `4` (число), действие — `"toggle"`. Результат сервиса: `{ ok: true, tasks: [...] }`.

При проверке с клавиатуры: Tab перемещает фокус по кнопкам, Enter и Space активируют нажатие. После изменения статуса задачи фокус сохраняется на кнопке «Выполнена» (если карточка осталась в списке) либо переходит на активный фильтр (если карточка исчезла из-за фильтра). После удаления задачи фокус также переходит на активный фильтр.

Отказ для некорректных идентификаторов обрабатывается корректно: при попытке изменить `data-task-id` на `777` (несуществующий id) выводится сообщение «Задача не найдена»; при значении `4abc` срабатывает проверка `Number.isSafeInteger(id)`, выводится сообщение «Некорректный ID задачи». В обоих случаях данные не меняются.
